This repository exists mostly so I can do this:

    nix run github:bugeats/claude --refresh

... and have a Claude Code instance running just the way I like it.

(and you can too)

The bundled guidance is opt-in. Pick an output style in `/config`: `arcs:manual` for the Compression Principle and working contract, or `arcs:auto` to add the checkpoint/negentropy/shipit workflow with automatic triggers. Leave it unset for a stock Claude Code with the skills available on request.
